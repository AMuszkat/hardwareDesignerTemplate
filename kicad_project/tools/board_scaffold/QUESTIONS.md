# Questions for the concept session — {{TITLE}} ({{ID}})

You own this file; the concept session reads it and answers in
`handoff/07_answers.md`. One question per `##` heading. It is the record of
every question whether the relay is on or off (`../RELAY_PROTOCOL.md`).

**Format** — keep it exactly, the concept session scans for it:

    ## Q<n> — <title, one line>
    **Status:** open · BLOCKING | open · not blocking | reopened | waits on the user | solved (rev R)
    **Need:** the fact, value or document, and where in the handoff it should have been.
    **Without an answer I would:** what you would otherwise do (you do NOT do it).
    **Working from:** the MANIFEST revision, if it differs from the block below.

- Numbers never repeat: Q<n> keeps its number for life.
- **Solved:** set `solved (rev R)` and delete everything under the heading but
  the status line. The title stays, so the numbering stays readable.
- **Reopened:** the answer did not resolve it — write why under the same
  number; do not open a new one.
- A question is a handoff defect only (`../CLAUDE.md`, "When you are stuck").
